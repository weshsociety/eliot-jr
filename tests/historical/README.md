# Tests historiques de lecture

Ces scripts documentent des étapes anciennes du développement du curriculum
Thoreau, lorsque seules quatre rencontres avaient été enregistrées.

La mémoire réelle d’Eliot-Jr contient désormais 21 rencontres et 21
apprentissages logiques. Elle ne doit être ni réinitialisée ni utilisée comme
fixture de test.

Ces scripts sont conservés sans modification comme traces historiques. Ils ne
sont plus exécutés automatiquement.

Leur couverture sera remplacée par des tests reproductibles utilisant des
répertoires temporaires et des données synthétiques, sans modifier les
registres vivants d’Eliot-Jr.
